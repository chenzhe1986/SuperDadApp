# 全能小学霸 · 小学知识问答 APP

一款专为小学生设计的**知识问答闯关**应用，使用 **uni-app（Vue3）** 开发，可打包成**安卓 App**或**微信小程序**。
题目涵盖语文、数学、英语、科学、历史、地理、生活安全和综合常识，寓教于乐，让孩子在闯关中积累知识。

> 本项目代码带有**详细中文注释**，方便非专业开发者阅读、维护与扩展。

---

## ✨ 功能特色

- **选年级闯关**：内置小学一年级至初三共 9 个年级题库（累计约 8900 题）。低年级以口算、乘法口诀、拼音、古诗、字母和安全常识为主，高年级以人文社科与科学常识为主，并预留了扩充其它年级的接口。
- **随机抽题**：每次闯关随机抽 20 题，科目与难度分布合理（先易后难）。
- **20 秒倒计时**：每题限时作答，超时自动判为未答。
- **即时反馈**：选项点击高亮，答对/答错都有动画 + 音效反馈。
- **得分统计**：闯关结束展示得分、正确率、用时。
- **错题本**：自动收集做错的题，随时回顾巩固。
- **音效开关**：可一键静音，音量控制在 60%，保护儿童听力。
- **儿童友好 UI**：马卡龙糖果色、加大字号、大圆角果冻质感（详见 `docs/UI设计规范.md`）。

## 🚀 快速开始（HBuilderX）

1. 下载安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)（选“App开发版”）。
2. 用 HBuilderX 打开本项目文件夹 `SmartKid`。
3. **运行到浏览器/模拟器**：菜单「运行」→「运行到浏览器」或「运行到手机或模拟器」。
4. **打包安卓 App**：菜单「发行」→「App-Android」，按向导操作（需 DCloud 账号）。
5. **发布微信小程序**：菜单「发行」→「小程序-微信」，用微信开发者工具打开生成目录后上传。

> 提示：`scripts/` 下的脚本需要本机安装 [Node.js](https://nodejs.org/) 才能运行，仅供开发维护使用，**不影响 App 打包运行**。

## 🧩 题库说明

题库为 JSON 文件，每题一行，字段如下：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| `id` | 题目唯一编号 | `"g4-001"` |
| `grade` | 年级 | `4` |
| `subject` | 科目 | `"语文"` |
| `difficulty` | 难度：简单/中等/困难 | `"简单"` |
| `type` | 题型（当前均为单选） | `"single"` |
| `question` | 题干 | `"..."` |
| `options` | 4 个选项数组 | `["A","B","C","D"]` |
| `answer` | 正确答案下标（0~3） | `1` |
| `explanation` | 简短有趣的解析 | `"..."` |

**四~初三（高年级段）**：共 6 个年级题库累计约 6000 题（各年级 1001~1024 题）。题库定位以**人文社科（语文、历史、地理、综合）与科学常识**为主，重在各科常识考察与学习，而非数学计算。人文社科与科学题均来自**人工校对的知识条目**（含古诗文名句、成语、文学常识、修辞、朝代与历史事件、省区与世界地理、安全与国情常识等）。数学题严格控制在全部题量的 10% 以内，且只保留**巧算技巧题**（如 35²=1225、53×57=3021 等）与**数学常识题**，不含纯计算题；其答案由程序直接计算保证正确。题库可通过 `scripts/generate-bank.js` 追加扩充（仅追加新题、不改动已有题；若知识池抽尽则如实少补，不用数学题填充）。

**一~三年级（低年级段）**：共 3 个年级题库约 2800 题（一年级 855 题、二年级 1017 题、三年级 927 题），由 `scripts/generate-bank-g123.js` 按低年级课标生成：
- 数学口算类（10/20/100 以内加减法、乘法口诀、有余数除法、周长、单位换算、钟表、找规律、两步应用题）由程序计算保证答案正确；
- 语文（拼音选读音、反/近义词、量词、笔顺常识、古诗接句与作者）与英语（字母启蒙、基础单词、情景句）、科学/安全/综合常识来自**人工校对的字典与条目池**；
- 生成后按题干去重、随机编号，可用 `node scripts/validate.js` 校验；重新生成会整体重建 grade1~3.json。

各年级科目分布大致如下（以四年级为例，人文社科与科学合计占比最高，数学不足 10%）：

| 科目 | 题量 | 科目 | 题量 |
| --- | --- | --- | --- |
| 语文 | 220 | 地理 | 111 |
| 科学 | 138 | 历史 | 107 |
| 英语（已有） | 240 | 综合 | 76 |
| 数学 | 87 | 安全 | 45 |

### 校验题库

修改题库后，在项目根目录执行：

```bash
node scripts/validate.js
```

脚本会检查 JSON 合法性、字段完整性、`options` 长度、`answer` 取值范围、`id` 唯一性，并统计科目/难度分布。

## ➕ 如何扩充其它年级

题库设计已预留扩年级能力，只需 **3 步**：

1. 在 `data/` 下新增题库文件，例如 `grade3.json`（格式同上）。
2. 打开 `utils/questionBank.js`，导入并注册到 `BANKS` 映射：
   ```js
   import grade3 from '../data/grade3.json'
   const BANKS = { 3: grade3, 4: grade4 }
   ```
3. 在首页年级列表里加上对应年级即可。

抽题算法、页面逻辑均无需改动，自动适配新题库。

## 🔊 音效

`static/sounds/` 下有 4 个音效：`click`（点击）、`correct`（答对）、`wrong`（答错）、`win`（胜利）。
它们由 `scripts/gen-sounds.js` 用纯代码合成，可重新生成或直接用同名 wav 文件替换：

```bash
node scripts/gen-sounds.js
```
