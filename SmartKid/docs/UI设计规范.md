# 全能小学霸 · UI/UX 设计规范

> 面向 **10 岁左右儿童**的界面设计规范。所有页面均遵循本规范，设计变量集中定义在 [`uni.scss`](../uni.scss)，改一处即可全局换肤。

---

## 一、设计理念

针对 8~11 岁儿童的认知与视觉特点，确立三条核心原则：

1. **色彩明快但不刺眼**：采用马卡龙糖果色系，适当降低饱和度，避免荧光色造成视觉疲劳。
2. **字号整体加大一档**：正文、题干比成人 App 更大，保护视力、降低阅读压力。
3. **大圆角 + 果冻质感**：圆润的形状 + 轻微弹跳动效，传递“友好、无压力、鼓励”的情绪。

---

## 二、色彩规范

### 2.1 主色板（马卡龙糖果色）

| 变量 | 色值 | 含义 / 用途 |
| --- | --- | --- |
| `$sk-primary` | `#4FA3F7` 天空蓝 | 主按钮、强调元素 |
| `$sk-secondary` | `#FFB84D` 暖阳橙 | 次级按钮、奖励元素 |
| `$sk-success` | `#6BCB77` 苹果绿 | 答对反馈（正向鼓励） |
| `$sk-danger` | `#FF8080` 珊瑚红 | 答错反馈（比正红柔和，不吓人） |
| `$sk-warning` | `#FFD166` 柠檬黄 | 倒计时警告 |

### 2.2 背景与文字

| 变量 | 色值 | 用途 |
| --- | --- | --- |
| `$sk-bg` | `#FFF9EF` 奶油米白 | 页面底色（比纯白柔和，久看不累） |
| `$sk-card-bg` | `#FFFFFF` | 卡片背景 |
| `$sk-text-main` | `#4A4A68` 蓝灰 | 主文字（代替纯黑，对比适中更护眼） |
| `$sk-text-sub` | `#9B9BB4` | 次要文字：说明、提示 |
| `$sk-text-light` | `#C5C5D8` | 占位、禁用文字 |

### 2.3 学科专属色

用于科目标签，帮助孩子建立“颜色—学科”的分类认知：

| 学科 | 变量 | 色值 |
| --- | --- | --- |
| 语文 | `$sk-subj-chinese` | `#FF8FAB` 樱花粉 |
| 数学 | `$sk-subj-math` | `#5C9DFF` 科技蓝 |
| 英语 | `$sk-subj-english` | `#B58CFF` 薰衣草紫 |
| 科学 | `$sk-subj-science` | `#52C4A0` 薄荷绿 |
| 历史 | `$sk-subj-history` | `#D2A06E` 古卷棕 |
| 地理 | `$sk-subj-geo` | `#4FC3D9` 湖水青 |
| 安全 | `$sk-subj-safety` | `#FF9F5A` 活力橙 |
| 综合 | `$sk-subj-misc` | `#F49AC2` 泡泡粉 |

> **对比度**：正文文字与背景对比度均满足可读性要求；答对/答错色块上的文字统一用白色，保证清晰。

## 三、字号规范（单位 rpx）

儿童阅读整体加大一档，题干区域特意再放大。

| 变量 | 尺寸 | 用途 |
| --- | --- | --- |
| `$sk-font-xs` | 24rpx | 角标、版权 |
| `$sk-font-sm` | 28rpx | 标签、辅助说明 |
| `$sk-font-base` | 32rpx | 正文、选项 |
| `$sk-font-md` | 36rpx | 中标题 |
| `$sk-font-btn` | 36rpx | 按钮文字 |
| `$sk-font-lg` | 40rpx | **题干文字**（重点阅读区） |
| `$sk-font-xl` | 48rpx | 页面大标题 |
| `$sk-font-huge` | 72rpx | 得分、倒计时等超大数字 |

## 六、组件规范

### 6.1 按钮

- **主按钮**：`$sk-primary` 填充 + 胶囊圆角 + 白色文字（`$sk-font-btn`）。
- **点击态**：轻微下沉 + 缩放（`scale 0.96`），配合 `click` 音效，模拟“果冻按压”。
- **尺寸**：主要操作按钮高度不小于 88rpx，方便小手指点击。

### 6.2 选项卡（答题页）

- 默认：白底、`$sk-radius-md` 圆角、`$sk-text-main` 文字。
- 选中/答对：`$sk-success` 描边或填充。
- 答错：`$sk-danger` 描边或填充。
- 选项之间间距 ≥ `$sk-space-md`，避免误触。

### 6.3 科目标签

- 使用对应“学科专属色”作背景，`$sk-radius-sm` 小圆角，`$sk-font-sm` 白色文字。

### 6.4 卡片

- `$sk-card-bg` 白底 + `$sk-radius-lg` 大圆角 + 柔和阴影，`$sk-space-lg` 内边距。

## 七、动效与音效

**动效**（时长控制在 200~400ms，缓动自然，不喧宾夺主）：

- 按钮点击：缩放果冻反馈。
- 答对：选项绿色高亮 + 轻微放大/对勾出现。
- 答错：选项红色高亮 + 轻微摇摆（提示但不惩罚）。
- 结果页：得分数字滚动增长。

**音效**（音量 60%，保护听力，可在设置中一键静音）：

| 音效 | 文件 | 场景 |
| --- | --- | --- |
| 点击 | `static/sounds/click.wav` | 点击按钮/选项 |
| 答对 | `static/sounds/correct.wav` | 回答正确 |
| 答错 | `static/sounds/wrong.wav` | 回答错误（柔和，不吓孩子） |
| 胜利 | `static/sounds/win.wav` | 闯关结束 |

---

## 八、无障碍与儿童友好细节

- **点击热区**足够大（≥ 88rpx），适配儿童手指精细度不足。
- **文字避免纯黑**，减少视觉刺激。
- **答错反馈用珊瑚红而非正红**，语气以“鼓励再来一次”为主，减少挫败感。
- **倒计时**临近结束时用 `$sk-warning` 提示，但不使用刺耳闪烁。
- **解析文字**简短有趣，帮助孩子理解而非说教。
